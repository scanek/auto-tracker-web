# 🚗 Бортовой Журнал автомобиля (Web / PWA)

> Современное, быстрое и удобное веб-приложение для ведения сервисной книжки, учета расходов на автомобиль, заправок, шин, напоминаний о ТО и заводской базы знаний.

🌐 **Рабочая веб-версия (GitHub Pages)**: [https://scanek.github.io/auto-tracker-web/](https://scanek.github.io/auto-tracker-web/)

---

## ✨ Возможности приложения

* 📱 **PWA (Progressive Web App)**: устанавливается на любой смартфон (Android / iPhone) или ПК прямо из браузера как нативное приложение.
* 🔒 **100% автономная работа (Offline-First)**: все данные надежно сохраняются прямо в вашем браузере (IndexedDB). Работает без интернета!
* 💾 **Резервное копирование и экспорт**:
  * Полный экспорт всех автомобилей, чеков и истории в один клик в файл JSON.
  * Восстановление из резервной копии.
  * Экспорт красивой сервисной книжки в PDF.
* 🌐 **Подключение собственного сервера (по желанию)**:
  * Если вы хотите синхронизацию между несколькими устройствами, в настройках приложения можно указать адрес своего бэкенд-сервера ([репозиторий бэкенда scanek/to_auto](https://github.com/scanek/to_auto)).
* ⚡ **Встроенная база знаний Changan CS55 Plus / UNI**:
  * 674 заводские электросхемы в высоком качестве с зумом и поиском.
  * Интерактивная схема предохранителей с распиновкой под регистратор (ACC, B+, GND).
  * 1391 код ошибок DTC с расшифровкой на русском языке.
  * Регламенты ТО, артикулы расходников и сервисные калибровки.

## 🛠️ Стек технологий

* **Фреймворк**: React 18, TypeScript, Vite 5
* **Стилизация**: Tailwind CSS (с поддержкой темной и светлой темы)
* **Графика и иконки**: Lucide React, Recharts
* **Локальное хранилище**: IndexedDB (LocalDatabaseEngine)
* **CI/CD**: GitHub Actions (автодеплой на GitHub Pages)

---

## 💻 Локальный запуск и разработка

```bash
# Клонировать репозиторий
git clone https://github.com/scanek/auto-tracker-web.git
cd auto-tracker-web

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать релизную версию
npm run build
```
